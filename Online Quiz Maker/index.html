How do I connect Firebase?
  1. Create a Firebase project and register a web app.
  2. Enable Email/Password sign-in and create a Firestore database.
  3. Publish the rules from firestore.rules.
  4. Paste your web configuration into firebase-config.js.
  5. For real login, open this folder with VS Code Live Server and reload. Sample quizzes can also be opened directly.

The README includes each step. No Python or payment details are needed to edit the code.
